# Plan history

The study plan was kept in a private Pantalytics repository
(`pantalytics/pan_ai_pro`, file `docs/plans/invoice-extraction-benchmark.md`)
while the study ran. Each file here is that plan at one commit, named
`<commit time UTC>_<commit hash>.md`; `LOG.txt` lists the commits. They show
what was written down when, the hypotheses included.

Redacted before publication: the name of the client whose own bills form a
later, private part of the study, and the accounting system that client
uses. Nothing else was changed.
